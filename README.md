# PlockaSvamp – offlinekartor

Vektorfiler (`.map` i Mapsforge-format) för Sveriges 21 län, till appen PlockaSvamp.

Kartorna är framställda från OpenStreetMap-data (Geofabrik Sweden PBF).
© OpenStreetMap-bidragsgivare. Licens: [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/).

Filerna publiceras som utgåvor (Releases), inte i git-historiken.

- Manifest: <https://github.com/SVTleecher/plockasvamp-maps/releases/download/maps-v1/manifest.json>
- En kartfil per län, till exempel Gotland: <https://github.com/SVTleecher/plockasvamp-maps/releases/download/maps-v1/gotland.map>
